# 02 · 避坑手册：症状 → 原因 → 修法 → 提前发现

> 合并了安史版（`A`）与黄巢版（`H`）实际踩过的坑。「提前发现」一栏是最重要的：它告诉你在哪个 Gate 就能拦住。

## 1. 版式与叙事

| # | 症状 | 原因 | 修法 | 提前发现 |
| :-- | :-- | :-- | :-- | :-- |
| H1 | 网页端生成成「左地图右人物」分屏 PPT | 提示词没给版式铁律，模型套用常见解说模板 | 交接时附 `00_rules.md` + `07_prompt_template.md` | G3 分幕表里出现常驻侧栏即驳回 |

## 5. 音频

| # | 症状 | 原因 | 修法 | 提前发现 |
| :-- | :-- | :-- | :-- | :-- |
| H14 | 音效完全不合拍 | 先定等距幕次再贴音效，没测原曲 | 先测拍（`04_audio.md` §1），SFX 全部 `nearest(beats, t)` | G2 / G5 诊断图上 SFX 竖线应与 beats 重合 |
| H15 | 音效太抓耳 | SFX 归一化峰值 `0.62` | 降到 `0.45`（约 −2.8 dB），减小 `amb` 比重 | G5 `SFX−BGM` 表 |
| A4 | BGM 一直被压、听起来在“抽搐” | 侧链触发源包含持续的 `amb` 风声 | 触发源只用 `highpass(battle,1200) + drums + rout (+clip_bus)` | G5 诊断图 `duck_gain` 曲线不该长时间贴底 |
| A5 | 一个尖锐刀声让其余音效全变小 | 用 `max(|x|)` 归一化 | 用 99.7% 分位数做参考电平 + `tanh` 软饱和 | G5 |
| A6 | 轻柔前奏听不见 / 高潮压过音效 | 用一个固定系数压整首 BGM | `envelope_points` 分段包络 | G2 结构表 + G5 |
| A7 | 分段拼接处音量掉坑 | 上段成片自带淡出，直接硬拼 | 保存 stems，交界处取未淡出的原曲重算 + 0.5 s crossfade | 拼接点前后 2 s 单独听 |
| A8 | 合集里同一段剧情播了两遍 | 上下半各自以同一短片收尾/开篇 | 合集从下半第一个非重复事件切入 | 抽拼接点前后帧 |
| H16 | 母带 −13.10 LUFS，成片变成 −13.2 | AAC 有损编码降低约 0.1 LUFS | 母带落在 −13.0 ~ −12.9；**测成片**；只改音频时 `-c:v copy` 重封装 | G6 |

## 附：像素角色三级分辨率

| 等级 | 原生分辨率 | 用于 | 参考 |
| :-- | :-- | :-- | :-- |
| 兵卒 / NPC | 32×32 ~ 36×36（4× 超采样绘制） | 千军同屏、云梯、行军算子 | `sprites.py::make_sprite` |
| 重要配角 | 64×64 起步；**有全屏转折剧场的，用 128×128** | 宿敌名将、副将 | `tang_warlords_sprites_128.py`（朱温/李克用实际为 128×128 × 4 帧） |
| 绝对主角 | 128×128 原生绘制（不是放大） | 全片人物线 | `huangchao_sprites_ultra.py`（5 阶段 × 4 帧 = 20 帧） |

> 修订：Drive 旧版 `02` 写“李克用、朱温用 64×64”，与实际交付的 128×128 精灵不符，已更正。

主角绘制技巧（`huangchao_sprites_ultra.py`）：
- 每种材质 5 ~ 6 档明暗色阶（`skin0~5`、`gold0~5`、`iron0~5` …），不平涂。
- `_face()` 锁定面部锚点（眉、鼻梁高光、须形），跨阶段只换头饰，保证“同一张脸”；支持 `feeling='angry'`、`turn=True`。
- `PixelCanvas.finish()`：先画内部细节，再对 Alpha 做 `MaxFilter(3)` 膨胀生成 1 px 外描边，不吞内部高光。
- 关键姿态独立重绘（如 `_fallen()` 卧倒 + 断旗），不靠旋转站姿。
