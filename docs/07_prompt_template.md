# 07 · 交接给网页端 / 其他 AI 模型的提示词模板

> 复制整段即可使用。核心目的：强迫新模型先读规矩和参考成品，并把分幕表卡在 G3 让用户拍板后再渲染。

---

## 模板一：新开一个历史兵棋视频项目（推荐）

```text
请接手制作历史兵棋科普视频《【战役名称，如：靖康之变 / 淝水之战】》，搭配指定 BGM：【音频文件名，如 xxx.mp3】。

⚠️ 开工前必须严格按以下顺序先阅读仓库规范与已验收参考工程，禁止自行发明「左地图右人物分屏 PPT」：
1. 先读根目录 AGENTS.md，再按顺序精读 docs/00_rules.md、docs/01_pipeline.md、docs/04_audio.md、docs/02_pitfalls.md；
2. 画面架构、地形质感、双向沙盘、96档不滞后战线与混音代码一律以 reference/huangchao/ 为首要模板（多段外插短片可补充参考 reference/anshi/）。

请严格按 docs/01_pipeline.md 的六个阶段推进，不要跳步：
- 第一阶段（G1）：完成 src/data_geo.py、data_routes.py、data_timeline.py 与 build.py 校验，若是流动作战必须逐幕写明旧地收复，并打印每幕攻方城池清单自查；
- 第二阶段（G2）：先将 BGM 转为 48kHz WAV（纯英文工作路径），用 librosa 实测 BPM / beats / 能量分段并输出 beat_map.png；
- 第三阶段（G3 暂停确认）：严格贴合实测音乐段落写出完整分幕表（包含每幕起止 beat、画面模式、敌我双方算子帅旗、版图占领与收复变化、主要 SFX），发给我确认后再动工渲染与全片混音；
- 第五、六阶段（G4–G6）：正式编码前必须先跑 tools/qa_tools.py 冒烟检验 + 关键帧实际出图目视；成片封装后实测最终 MP4 的 ebur128 响度，确保落在 -13.1 ~ -12.7 LUFS（禁止整轨事后 AGC）。
```

## 模板二：让模型审查 / 重置已做坏的半成品

```text
我手头这版历史兵棋视频（工作目录：【如 D:\wargame\xxx\】）出现以下问题，请你参照仓库 making-history 的规范与 reference/huangchao/ 标准成品进行彻底排查和重置：
【按需勾选：
- 出现了左地图右人物分屏 / 战场只有单方面部队跑图或打空气；
- 仓库里有人物多帧像素精灵，但成片里没给完整四帧转折戏份；
- 势力扩张滞后于进攻箭头，或大军撤走后故地没有翻红收复；
- 西部地图大片平地缺青藏/横断立体地貌；
- 音效和 BGM 明显不合拍 / 太刺耳抢歌 / LUFS 没落进 -13.1 ~ -12.7 LUFS。】

请按 docs/00_rules.md 和 docs/02_pitfalls.md 逐项对照修复，先用 15 秒跑完所有幕次的冒烟测试并抽样导出关键帧 PNG 检查构图无遮挡后，再启动全片渲染；若仅调整音频 LUFS，直接用 -c:v copy 秒级重封装已有无声视频，无需重渲画面。
```
