# 09 · 实战复盘：赵匡胤为何能黄袍加身？

第三版把「边报告急 → 出师 → 陈桥拥立 → 收禁军兵权」串成一条因果线。观众能先看见后周为何出兵，再理解赵匡胤为何担心同样的事发生在自己身上。这一案例来自项目内的第三版交付与看片反馈。

## 一、先写历史事实，再写画面

| 信息类型 | 本片怎么处理 | 可复用方法 |
| --- | --- | --- |
| 可定年的事件 | 960 年建宋；《续资治通鉴长编》将石守信等四人的禁军军职调整记在 961 年；979 年宋太宗灭北汉。 | 把年份、行动主体和结果写进同一张事件表。结尾年表保留足以回答观众疑问的节点。 |
| 来袭消息 | 边报告知契丹、北汉来袭；朝廷命已经担任殿前都点检的赵匡胤率军北御。 | 字幕写清消息来源和当时职务；沙盘写「边报示意」，兵棋队数只服务于画面。 |
| 史载有异与戏剧化场面 | 《宋史·石守信传》把宴饮记在乾德初。《长编》把军职调整记在建隆二年。展现四将的集体反应，落符镜头标「演绎」。 | 年表标注制度事件；宴席、对白、道具动作按史料强度编排。字幕和道具刻字都纳入史实抽检。 |

## 二、把压力、选择和代价分别拍出来

以下时间码对应本片第三版，复用时按本项目实测拍点重排。

| 片段 | 本片镜头顺序 | 短片复看时问什么 |
| --- | --- | --- |
| 0:00–0:08 开场 | 动态地图推进，转入陈桥驿。 | 首帧接住封面的题眼，画面本身已经在讲新的信息；地名能读清。 |
| 0:37.80–0:47.77 边报告急 | 带羽纹的飞矢掠过边旗 → 镇州与定州接连告警 → 多队兵棋压境，守军退关、禁军北上 → 驿使到朝。 | 观众能指出谁退、谁进、谁下令吗？地图一眼能读出主行动吗？ |
| 0:53.27–1:23.67 夜议到披袍 | 火把剪影聚拢 → 低机位看兵士围拢 → 袍从画面上方落下、金光扫过织纹 → 袍落在肩后，胸甲可见 → 短停，赵匡胤握拳抬眼、约束诸将。 | 静音能读出由惊怔到决断吗？高光跟着布料和肩部走吗？单看落肩前后两帧，衣甲前后关系是否清楚？ |
| 2:20.50–2:29.50 群将请解兵权 | 四将同席 → 黄袍画面短暂回闪 → 对视、低头 → 四符先后落桌 → 交代诸将请解兵权。 | 人数、身份和反应都可辨吗？片尾让观众想起陈桥发生了什么吗？ |

- **地图读法**：主线给当前行动；次线用轻量标注；守势用盾牌表示。新势力初现先标位置和身份，有行动时才绘制对应路线。先看无标签画面能否读出进退，再看信息层有没有遮挡。
- **角色情绪**：让转折在姿势、视线和停顿里发生。本片肩后黄袍逐帧合成，光附着在袍边与织纹；群将的轻微动作错开，保留彼此观察的时间。
- **模型尺度**：高分辨率透明精灵用于刻画脸型、帽形、胡须与衣甲；以可见像素包围框和脚底锚点布置画面。对比同景深成人的站高、头身比和共用地面线；再检查幼主、前后景或近景各自有清楚的比例依据。人物能在成片显示尺寸下认出，才算细节有效。
- **物件和文字**：挑一个物件承接每段动作（飞矢、黄袍、铜符）；挑少数关键台词做居中强调，例如「边报告急」「愿立点检」「黄袍加身」。文字短震后停稳，给人脸、道具和底部字幕留出空间。

## 三、用同一事件时刻驱动画面与声音

为边报、袍落肩、放下第一枚军符等转折记录可定位的时间或帧号。用同一条记录驱动特写、字幕出现和对应声效。紧迫段可逐层引入短促箭啸与蹄声；披袍段用布响、低鼓和短停拉开前后；片尾让杯盏与几声错开的落符单独可闻。先用转折短片看听感，再测最终 MP4 的整片响度与真峰值。局部更轻可以是演出安排，判断依据是对白、物件声是否可辨和进入下一幕是否自然。

## 四、先交转折短片，再交整片

1. 长渲染前先给边报、披袍、交权各出一段可播放样片。逐段看前因、动作和结果；抽帧查看人物尺度、字幕边界和高光遮挡。正式混音后再复看同一时间码。
2. 每次返修写新版本文件。审核前记录版本路径、文件大小、指纹、改动范围与关键时间码；主交付名需要更新时，保留已送审版本及其指纹。
3. 在实际交付文件上检查流参数、解码帧数和全流错误，逐幕抽查并实测封装后的积分响度与真峰值。团队执行检查与用户对作品的验收各自记录。

本片第三版交付报告记录：1920×1080、30 fps、4,858 帧、161.93 秒、H.264 + 48 kHz 立体声 AAC，整片 −13.0 LUFS、真峰值 −1.8 dBTP。这些数值描述本次交付；项目的计划帧数与音频目标应以各自的分幕表和交付规格为准。通用检查见 [流水线](01_pipeline.md)、[混音](04_audio.md) 和 [验收清单](06_acceptance_checklist.md)。
