## 一、从推倒重来到终版定稿：重点解决了哪四件事

### 1. 流动作战状态机：杜绝“只蓝不红”与开场孤立蓝点

- **旧版问题**：`LIANGTIANPO` 初始误设为 `QI` 导致 Day 0 起即见异色孤点；时间轴只记录占领，大军离境后山东、河南、湖北、岭南长期残留蓝色，直到公元 884 年还像是半壁江山都在黄巢手里。
- **终版解法（`data_geo.py` + `data_timeline.py`）**：
  - `LIANGTIANPO` 改回 `TANG`；
  - 从 `T04` 起随主体转战逐幕写回朝廷收复：`T04` 收复冤句/长垣，`T05–T09` 陆续收复汴陈蔡、蕲黄、采石、宣州、建福、岭南、潭州江陵，`T13–T14` 关中洛阳翻红后只留退守的陈州/蔡州，`T15` 仅剩泰山 `LANGHUGU` 一点孤蓝，`T16` 全灭归唐（66 次控制权变更）。
  - 渲染器直接读取编译快照 `dict(tl[eid]["city_control"])`，不再在视图层额外打补丁。

### 2. 视口扩张后的西部 3D 地貌 + 96 档不滞后战线

- `hc_terrain.py` 定义关注域 `LON0=102.0, LON1=121.6, LAT0=20.0, LAT1=39.8`，经 `fit_aspect_bounds` 按 `16:9` 画幅横向延展后，实际视口横跨约 `94.4°E ~ 129.2°E`，正好将青藏高原东缘与横断山脉纳入左半屏。若只在东部塑山，左侧会大片发平。
- 因此 `build_relief_terrain` 加入了**青藏高原生境抬升 + 横断三江并流平行峡谷雕刻 + 四川盆地四周环山 + 云贵高原 + 二维域扭曲（domain warp）**。
- 势力平滑半径扩大并把 `gaussian_filter` 的 `sigma` 由 `2.8` 提至 `3.8`，`_draw_macro` 结合 `s0 → s_mid → s1` 三段场将前锋推动细分到 **`96` 档**（压缩于 `u / 0.72` 内，城池 `u ≥ 0.36` 翻色），彻底消除“人到第三步、边界还在第二步”的滞后。

### 3. 从“主角独角戏”到“名将四帧演进 + 敌我双向战场”

- **宏观每幕**：为 `T02 ~ T15_REV` 配齐 `宋威 / 高骈 / 张承范 / 王铎 / 朱温 / 李克用` 帅旗及 `QI / TANG / SHATUO` 正反向兵种（通过循环构建全组合字典，避免 `KeyError`）。行军标签在算子与帅旗**之后**绘出并加半透明圆角底框。
- **三场 3D 战术沙盘（`hc_tactical.py`）**：
  - **`B_GZ`（广州）**：城头 `唐守将` + 6 名守军 + 4 队城外阻击唐骑，与齐军 6 队架梯步兵、4 队破门后入城铁骑双向箭雨绞杀；
  - **`B_TG`（潼关）**：`张承范` 关城守军迎战正面 `尚让` 梯队，`林言` 奇兵自 `禁谷奇袭山道` 绕后破关；
  - **`B_WMD`（王满渡）**：`李克用`（6 队沙陀黑骑）与 `朱温`（3 队宣武红骑）分从东西浮桥北岸杀向 `尚让`、`黄巢`，**进攻箭头止步于北岸桥头入口**，完整露出桥南白刃肉搏与火烟。
- **名将四帧转折（`tang_warlords_sprites_128.py` + `_draw_cutscene`）**：
  - `T13`（7.0s）：前 26% 切回棋盘见同州失守断粮，后 74% 展示黄巢与 **朱温完整 4 帧**（`据城观望 → 拔剑背齐 → 献印降唐 → 宣武赤旗`）；
  - `T14_LK`（4.0s，踩 Drop 2 强鼓）：**李克用完整 4 帧**（`雁门驻马 → 独眼挽弓 → 鸦军突袭 → 跃马追击`），底图同步演进沙陀骑兵自雁门冲入关中。

### 4. 三段式验收实操成果

1. **全幕 18 幕 × 3 点冒烟**：一眼捕获了 `_path_pos` 二元组传参 `IndexError` 与 `('QI', 'militia', True)` 缺失 `KeyError`。
2. **PNG 目视抽检**：实际打开样张发现并修复了“行军标签被高骈/黄巢帅旗切半”“王满渡箭头盖住西浮桥混战”“初版上下黑条遮住海南/辽东湾”以及“长江以南过平、左下角东南亚过空”的问题。
3. **MP4 响度微调**：首遍母带 `-13.10 LUFS` 封装后实测成了 `-13.2 LUFS`；只改音频增益（`base_curve * 1.17`）重算 WAV 后用 `-c:v copy` 秒级重封装，终版实测 **`-13.0 LUFS / TP -0.9 dBFS`**（`24.59 MB`），省掉重渲视频时间。

### 5. 东亚全海岸线、朝鲜半岛/日本列岛、江南丘陵与 16:9 紧凑缩放升级（终版）

- **完整东亚岸线与离岛扣海成陆（`data_geo.py` + `hc_terrain.py`）**：地理包围盒扩至 `LAT_BOUNDS=(18.0, 41.2)`、`LON_BOUNDS=(102.0, 123.5)`，新增 `ISLAND_LANDMARKS`（琼州、振州、流求(台湾)、澎湖）；升级 `SEA_POLYS` 为高精度辽东湾—渤海—山东—长江口—浙闽—珠江口—雷州半岛—北部湾岸线，并补全**朝鲜半岛**（图们江—日本海—釜山—西南海岸—西朝鲜湾）；在 `ISLAND_POLYS` 从 `sea_mask` 扣海成陆做出台湾、海南、澎湖、舟山、济州岛、对马/五岛、**日本九州/四国/本州中西部（含濑户内海）及琉球弧岛**，补充台湾中央山脉、海南五指山、朝鲜长白/太白与日本山地主脊，补全三方 `"TANG"` 背景锚点，校验 `31` 座内地城池 `0` 座落海。
- **江南—两广丘陵三级地貌与左下角防留白**：补充江南/浙闽/两广丘陵基底与雪峰/罗霄/黄山/戴云/十万大山/云开山脊、赣江与红河水系，叠加双尺度 `hill_knolls` 起伏肌理；使用 `fit_aspect_bounds(..., x_stretch=1.22)` 放大核心战区并裁去西侧空旷东南亚；顶部改左置圆角标题底框 + `68px` 底条完整露出辽东湾与海南岛。
