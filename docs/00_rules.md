# 00 · 硬性铁律（违反即判废）

> 适用：所有「历史兵棋科普视频」新作 / 续作 / 重制。
> 本版相对 Drive 旧版 `00_云端AI生成铁律与防跑偏规范` 的修订见文末「修订记录」。

---

## A. 画面版式

**A1. 全屏棋盘为主体，禁止常驻分屏**
- ❌ 左 `1280×1080` 地图 + 右 `640×1080` 常驻人物/文字栏（退化成解说 PPT）。
- ❌ 常驻画中画（PiP）。`pip` 镜头只允许作为 ≤ 6 s 的临时插入。
- ✅ 时长配比（以已验收的黄巢版实测为基准，见 `05_case_huangchao.md`）：

| 画面模式 | 建议占比 | 黄巢版实测 |
| :-- | :-- | :-- |
| `macro` 全屏宏观棋盘 | **≥ 55%** | 85.2 s / 58.1% |
| `tactical` 3D 战术沙盘 | 15% ~ 25%，至少 2 场 | 26.3 s / 17.9%（3 场） |
| `cutscene` 剧情剧场 | **≤ 25%**，3 ~ 5 处，单次 4 ~ 9 s | 35.1 s / 23.9%（5 处） |

**A2. 宏观棋盘必备视觉元素**
- 3D 立体地形：Ridged Multifractal + 315° Hillshade + 域扭曲顺坡纹理。
- 势力染色：暖红（朝廷/守方）vs 冷蓝（叛军/攻方）无缝过渡 + 「白光晕 + 深墨实线」战线。
- `◎` 靶心城池、重檐关隘城楼、渡口标点、锯齿牙边竖幅帅旗、4× 超采样兵棋算子、双描边动态箭头。
- HUD：顶部左对齐白字粗黑边大标题（重点词 `#FFE04D`），底部居中半透明黑底字幕条，左下角图例 + `Day N/总天数`。

**A3. 地形必须完整且分出「平原 / 丘陵 / 高原山脉」三级地貌**
- 视口覆盖中国中西部时，必须塑造青藏高原东缘抬升、横断山脉南北向平行峡谷、四川盆地环山、云贵高原、秦岭。不允许西半边是平地，也不要为了撑 `16:9` 比例在左下角露出大片无肌理的东南亚空地（可用 `fit_aspect_bounds(..., x_stretch=1.22)` 适度紧凑放大视口并收紧西南角）。
- 长江以南（江南丘陵、浙闽丘陵、两广丘陵）不可整片涂成华北式大平原：须区分平坦冲积平原（华北、关中、成都盆底、洞庭/鄱阳/珠三角）与南方中低丘陵（密集 `hill_knolls` 凹凸起伏 + 雪峰/罗霄/黄山/戴云/十万大山支脉）。
- 包含海南岛（`18°N`）与渤海辽东（`41°N`）的大跨度岸线时，需用 `ISLAND_POLYS` 从 `sea_mask` 扣海成陆做出台湾/海南/澎湖三维浮雕与浅海光晕，**顶部改用左置圆角标题框 + 底部 `68px` 精简字幕条**，绝不能让上下黑边遮住海南或辽东湾，且改完海岸线必检全部城池落在 `land_mask` 内。
- 视口向右涵盖 `124°E–138°E` 东亚海疆时，**必须同步补全朝鲜半岛岸线与山脊（长白—盖马—太白）、济州岛、对马/五岛、九州、四国、本州中西部（含濑户内海）与琉球弧岛**，不得将朝鲜半岛以东留成一片真空黑蓝海洋。
- **地名标注必须严格使用所演绎朝代的当世历史政区与古称（禁止直接印上近现代地名）**：例如隋唐时期地图应标 **「流求」** 而非「台湾」，按朝代分别标 **「新罗 / 高丽 / 朝鲜」** 而非现代词汇「朝鲜半岛」，海外标 **「倭国」** 等当世称谓，琼州岛标 **「琼州 / 珠崖」** 而非「海南」，西南与西部标 **「吐蕃高原」「剑南巴蜀」「南诏·黔中」** 而非现代「青藏/云贵/四川盆地」等教材名词；现代对应地名只允许写在 `data_geo.py` 的 `"modern"` 注释字段中。

**A4. 至少 2 场全屏 3D 战术沙盘**（独立 1920×1080 地形 + 逐帧确定性运动 + 箭雨 / 刀光血花 / 火烟 / 折旗）。

## B. 战场调度

**B1. 每一幕都要有敌我双方。** 宏观棋盘每幕至少 1 组敌方算子或帅旗与我方形成对向关系（截击、追剿、守城、合围）；战术沙盘双方各 ≥ 5 个 `Actor`，有双向箭雨与接战。

**B2. 流动作战必须写收复。** 主力离开且无留守的城池 / 关隘 / 渡口，必须在下一个合理的时间轴事件里翻回原阵营。终局只保留史实残余据点。数据层先做（`city_control`），渲染层不要打补丁。

**B3. 势力边界不落后于箭头。** 用 `s0 → s_mid（注入前锋锚点）→ s1` 三段场插值；边界在幕进度 `u ≈ 0.72` 前完成过渡，城池图标在 `u ≈ 0.36` 翻色，与箭头头部同步。

**B4. 已有的人物多帧精灵必须用满。** 仓库里有 N 帧动作的历史人物，就给他一个完整播放 N 帧的转折镜头，并配姿态字幕（例：朱温 `据城观望 → 拔剑背齐 → 献印降唐 → 宣武赤旗`）。

**B5. 文字不被遮挡。** 箭头标签、城名、帅旗之间不能互相压盖；标签在所有算子与帅旗**之后**绘制，带底框。

**B6. 弓手须多轮齐射，射毕转近战小兵。** 战术沙盘不得让每个弓手全场只射一箭后原地挂机：应在近战接触前按节拍安排**多轮错峰齐射**（每名弓手至少 2～3 轮放箭，形成持续可见的箭雨波次）；齐射窗口结束、进入接战或破城阶段后，弓手须切换为同阵营常规近战步兵（持刃推进、参与劈砍与伤亡结算），完成兵种状态闭环。

## C. 物理与军事写实

- **C1 城不在水上**：临河城池落在岸边陆地；河心城须画出岛体与浮桥。
- **C2 骑兵不飞墙**：只有步兵爬云梯；骑兵在城门破开后经门洞入城。
- **C3 过河必有桥/渡口**：所有行军路径经过可见的桥、浮桥或渡口。
- **C4 箭头不盖肉搏**：战术箭头止步于城门外 / 桥头，不压在接战小人上。

## D. 音频（详见 `04_audio.md`）

- **D1 先测后切**：BGM → 48 kHz WAV → librosa 测 BPM、beats、RMS、30–140 Hz Bass 包络 → 画出 Intro / Build / 抽空 / Drop / Breakdown / Outro → 再分幕。禁止先写等距幕次再去凑音乐。
- **D2 叙事能量对齐**：主攻城 / 决战放在 Drop；静谧 Breakdown 放行军、劝降、潜行；结尾折旗踩最后一记重拍后随 Outro 淡出。
- **D3 所有 SFX 量化到真实 beats**（`nearest(beats, t)`）。强节拍电子乐禁止铺持续人群喧哗、长马蹄循环、无拍点乱鼓。
- **D4 电平**：SFX 归一化峰值从 `0.45` 起步；分段 RMS 的 `SFX − BGM` 一般在 `−9 ~ −1 dB`，Breakdown 段可到 `+2 dB`，任何段落不得持续 `> +4 dB`。
- **D5 响度**：混音只做 `0.89` 峰值保护，禁用整轨 AGC；**对最终 MP4** 跑 `ebur128`，积分响度必须在 `−13.1 ~ −12.7 LUFS`。

## E. 工程

- **E1 字体**：不得只写死一种平台路径。按 `Windows (C:/Windows/Fonts/msyhbd.ttc, STZHONGS.TTF) → macOS → Linux (Noto CJK)` 顺序探测，找不到时报错说明缺哪个字体，而不是静默回退成方块字。
- **E2 路径**：工程路径一律相对 `ROOT = Path(__file__).resolve().parents[1]`；工作目录用纯英文路径（中文路径会让部分音视频库报编码错）。
- **E3 依赖自检**：交付前确认所有 `import` 模块都在仓库中。
- **E4 先验后渲**：全片编码前必须通过 `01_pipeline.md` 的 G4 关卡（全幕冒烟 + 关键帧目视）。
