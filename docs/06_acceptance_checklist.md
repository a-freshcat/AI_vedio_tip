# 06 · 逐关验收清单（G1 – G6）

> 每次只看当前正在跑的那个 Gate，全打勾后再进入下一阶段。

## G1 · 数据编译（`python src/build.py`）
- [ ] `build.py` 退出码 0，无孤立引用、无超视口坐标、时间严格递增
- [ ] 打印每个事件快照里的攻方城池清单：**开局无误设蓝点**（如历史上的梁田坡）
- [ ] 流动作战作品：主力离开的区域在后续事件里明确翻回 `TANG` / 守方，终局只留史实残部据点

## G2 · BGM 声学扫描
- [ ] BGM 已转 `48000 Hz` 立体声 WAV，工程路径无中文
- [ ] 用 `librosa` 测出实测 `BPM`、`beats` 数组、强 onset 与分段能量（Intro / Build / 抽空 / Drop / Breakdown / Outro）
- [ ] 输出并查看 `*_beat_map.png`，分段边界与听感对齐

## G3 · 分幕表（交用户确认 🧑）
- [ ] 每幕起止时间 `t0 / t1` 均对齐真实 beat，核心战役放在 Drop，悲凉/潜行放在 Breakdown/Outro
- [ ] 模式时长占比符合铁律：`macro ≥ 55%`，`tactical ≥ 2 场 (15%~25%)`，`cutscene ≤ 25% (3~5 处)`
- [ ] 每幕都有敌我双方算子/帅旗
- [ ] 仓库已有的多帧人物精灵全部排进了完整转折戏份
- [ ] **已展示分幕表并获用户确认再动手写大量画面/全量渲染**

## G4 · 画面冒烟 + 目视检查（全片编码前必过）
- [ ] 全部 `acts` 的 `u ∈ {0.15, 0.55, 0.92}` 冒烟通过，零 `KeyError` / `IndexError` / 缺字体
- [ ] 实际保存并目视查看每种模式、每场沙盘、每个人物剧场的样本 PNG：
  - [ ] 视口覆盖西部时，青藏/横断/四川盆地/云贵地形完整，不是大片平地
  - [ ] 同幕 `u=0.3 / 0.5 / 0.7` 抽帧确认战线不滞后于箭头
  - [ ] 城池不浮在水面；骑兵不飞墙；过河有桥或渡口
  - [ ] 箭头不压盖接战小人；标签文字不被帅旗挡住
  - [ ] 上面不出现常驻左右分屏人物卡

## G5 · 音频合成与混音
- [ ] 按曲风选择预设（交响 A `peak=0.58` / 强节拍电音 B `peak=0.45` + 量化 `beats`）
- [ ] 侧链触发源**不含 `amb` 环境风噪**；不使用整轨后置 AGC
- [ ] 查看终端逐幕表：电音版 `SFX − BGM` 大体在 `−9 ~ −1 dB`（Breakdown `≤ +2 dB`）
- [ ] 查看 `*_mix_timeline.png` 四合一诊断图：无长条贴底抽搐、无过载爆音
- [ ] 母带 WAV 实测 LUFS 在 `−13.0 ~ −12.9 LUFS`（预留约 0.1 dB 给 AAC），峰值 `≤ 0.89`

## G6 · 成片与交付（`python tools/qa_tools.py`）
